scripts package
================

Standalone CLI driver scripts under ``backend/scripts/``. These are not part
of the ``global_mosaic`` package (no ``__init__.py``, not importable as
``global_mosaic.scripts``) -- each is a top-level runnable module documented
here by module name only, made importable to autodoc by adding
``backend/scripts`` directly to ``sys.path`` (see ``conf.py``).
